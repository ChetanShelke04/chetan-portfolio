# Chetan Shelke — Portfolio Website

## Core Development Rules
- **Never invent experience, metrics, titles, dates, or skills.**
- **Use only data from `src/data/resume.js`.**
- Modern, premium UI with dark/light themes, sleek glassmorphism, responsive layout, and fluid animations.
- Pure frontend React application (Vite, React Router v7, Framer Motion, Lucide React, @react-pdf/renderer).
- Zero external backend required (Contact form uses Formspree/EmailJS, Resume Builder runs fully client-side).
